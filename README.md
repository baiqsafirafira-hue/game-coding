# GameCoding - Asah Logika Pemrogramanmu 🚀

**GameCoding** adalah permainan edukasi interaktif berbasis web yang dirancang untuk menguji wawasan dan logika pemrograman Anda. Dengan antarmuka modern yang futuristik, pemain dapat belajar sambil bermain melalui berbagai tantangan seru.

## 🎮 Fitur Utama

*   **Kuis Logika:** Jawab pertanyaan pilihan ganda seputar konsep dasar pemrograman.
*   **Tebak Logo:** Uji pengetahuan visualmu terhadap logo teknologi populer (HTML, CSS, JS, React, dll).
*   **Tulis Kode:** Latih ketepatan penulisan sintaks kode yang sebenarnya.
*   **Multi-Bahasa:** Pilih tantanganmu sendiri! Tersedia soal untuk:
    *   HTML
    *   CSS
    *   JavaScript
    *   Python
    *   Java
*   **Tingkat Kesulitan:** Tantang diri Anda dengan mode Normal, Sedang, hingga Sulit. Sistem skor dinamis memberikan poin lebih tinggi untuk kesulitan yang lebih tinggi.

## 🛠️ Teknologi yang Digunakan

*   **HTML5** - Struktur konten.
*   **CSS3** - Desain modern, responsif, dan efek animasi (Glassmorphism & Cyberpunk style).
*   **JavaScript (Vanilla)** - Logika permainan, manajemen state, dan interaksi DOM.
*   **Font Awesome** - Ikon untuk logo dan UI.

## 🚀 Cara Bermain

1.  Buka [Website GameCoding](https://baiqsafirafira-hue.github.io/game-coding/) (jika di-hosting) atau buka `index.html` di browser Anda.
2.  Pilih Mode Permainan (Kuis, Logo, atau Tulis Kode).
3.  Pilih Bahasa Pemrograman yang ingin diuji (kecuali mode Logo yang otomatis campuran/acak).
4.  Pilih Tingkat Kesulitan.
5.  Kumpulkan skor sebanyak mungkin sebelum nyawa habis!
