# GameCoding - Asah Logika Pemrogramanmu 🚀

**GameCoding** adalah permainan edukasi interaktif berbasis web yang dirancang untuk menguji wawasan dan logika pemrograman. Dengan antarmuka modern yang futuristik, pemain dapat belajar sambil bermain melalui berbagai tantangan yang mencakup bahasa HTML, CSS, JavaScript, Python, dan Java.

Link Demo/Website: [https://baiqsafirafira-hue.github.io/game-coding/](https://baiqsafirafira-hue.github.io/game-coding/) *(Jika Anda mengaktifkan GitHub Pages)*

## Fitur Utama 🌟

*   **🧠 Kuis Logika**: Jawab pertanyaan seputar konsep dasar pemrograman.
*   **🎨 Tebak Logo**: Uji pengetahuan visualmu terhadap logo teknologi populer.
*   **💻 Tulis Kode**: Latih ketepatan penulisan sintaks kode yang benar.
*   **🌐 Multi-Bahasa**: Pilihan soal spesifik untuk berbagai bahasa (HTML, CSS, JS, Python, Java) atau mode Acak.
*   **⚡ Tingkat Kesulitan**: Tantang dirimu di level Normal, Sedang, hingga Sulit dengan sistem skor dan nyawa.
*   **🏆 Sistem Reward**: Dapatkan predikat seperti "Legendary Hacker" berdasarkan skor akhirmu.

## Teknologi yang Digunakan 🛠️

*   **HTML5** - Struktur konten
*   **CSS3** - Styling modern (Glassmorphism, Gradient, Animasi)
*   **JavaScript (ES6+)** - Logika permainan interaktif
*   **FontAwesome** - Ikon visual

## Cara Bermain 🎮

1.  Pilih mode permainan (Kuis, Logo, atau Syntax).
2.  Pilih bahasa pemrograman yang ingin dikuasai (kecuali mode Logo yang otomatis acak).
3.  Tentukan tingkat kesulitan.
4.  Jawab pertanyaan dengan benar untuk mengumpulkan skor tertinggi!
